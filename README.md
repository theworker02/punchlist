# punchlist

Punch filesystem list paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/punchlist/

## Install / run

```bash
git clone https://github.com/theworker02/punchlist.git
cd punchlist
node src/cli.js
node --test
```
